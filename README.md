# The Strongest FNF Engines

A community-style ranking of **Friday Night Funkin' (FNF) engines**, split into **Haxe/HaxeFlixel engines** and **Non-HaxeFlixel / Other Haxe engines**. These rankings are based on my current opinions and performance tests, so feel free to suggest other engines!

## Haxe / HaxeFlixel Engines

1. **S2X** — Might be stronger, but who knows.
2. **H-Slice+JS** — I might be wrong about this one, so feel free to correct me.
3. **H-Slice** — The original Redux engine, made using P-Slice.
4. **HRK Engine** — HRK's original engine based on Psych Engine 0.7.3.
5. **JS Engine** — Based on Psych Engine 0.6.3.
6. **DenpaEx** — I think this is based on Psych Engine 0.5.3.
7. **Denpa** — Based on Psych Engine 0.6.3.
8. **ADR Engine** — Based on Psych Engine 1.0.4; described as a vibe-coded engine.

## Non-HaxeFlixel / Other Haxe Engines

2. **SDL3 Showcase**
3. **Rust Engine** — Andre's former best-performance engine. Rest in peace to the project: the code couldn't be found, and it was also vibe-coded.

## Rules for FNF Engine Classification

### Rule 1 — Existing Engine Required

To be considered an FNF engine on this list, a project must be a fork of an existing FNF engine, such as Psych Engine, Kade Engine, or another legitimate FNF engine.

### Rule 2 — Showcases Are Not Engines

Projects created entirely from scratch are classified as showcases rather than FNF engines under this list's rules, even if they can run FNF songs or achieve excellent performance.

### Rule 3 — Performance Doesn't Determine Classification

A showcase can outperform every engine on this list, but it will still be classified as a showcase if it was built from scratch.

### Rule 4 — Genuine Forks Only

Simply renaming a project or claiming it is based on an existing engine is not enough. The project should have a verifiable connection to its original codebase.

### Rule 5 — AI-Assisted Coding Is Allowed

Using AI to help develop an engine is allowed. However, the project must still meet the engine classification requirements.

### Rule 6 — Rankings Are Based on Personal Testing

Rankings reflect my own opinions and performance tests using my lag tester. Results may vary depending on hardware, operating systems, settings, and testing conditions.

### Rule 7 — Community Suggestions Are Welcome

Anyone can suggest an engine, correct information, or submit performance results through the Issues tab. Submissions may be tested before being ranked.

### Rule 8 — Classification Comes First

Before a project is ranked, it must qualify for the appropriate category under these rules. Projects that do not qualify as engines may be listed as showcases instead.

**Important:** The rankings represent my personal testing and opinions. Being ranked highly does not automatically mean a project is an officially recognized FNF engine.
