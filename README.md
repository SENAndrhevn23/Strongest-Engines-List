# The Strongest FNF Engines

A community-style ranking of **Friday Night Funkin' (FNF) engines**, split into **Haxe/HaxeFlixel engines** and **non-HaxeFlixel engines**. These rankings are based on my current opinions and performance tests, so feel free to suggest other engines!

## Haxe / HaxeFlixel Engines

1: **S2x** - Might be stronger, but who knows
2. **H-Slice+JS** — I might be wrong about this one, so feel free to correct me.
3. **H-Slice** — The original Redux engine, made using P-Slice.
4. **HRK Engine** — HRK's original engine based on Psych Engine 0.7.3.
5. **JS Engine** — Based on Psych Engine 0.6.3.
6. **DenpaEx** — I think this is based on Psych Engine 0.5.3.
7. **Denpa** — Based on Psych Engine 0.6.3.
8. **ADR Engine** — Based on Psych Engine 1.0.4; described as a vibe-coded engine.

## Non-HaxeFlixel / Haxeflixel Engines

1. **iutk Engine** — A custom-made FNF engine written in Haxe.
2. **SDL3 Showcase**
3. **Rust Engine** — Andre's best-performance engine. Rest in peace to the project: the code couldn't be found, and it was also vibe-coded.

## Want to Add an Engine?

If you want to add an engine of your own or someone else's, please share a **download link** or a **project link** in the [Issues](../../issues) tab. I'll gladly test its performance using my lag tester!

> **Note:** These rankings and descriptions are personal opinions, and some engine details may need correction. Feel free to open an issue with updated information or suggestions.


## Rules for FNF Engine Classification

1. **Existing Engine Required** — To be considered an FNF engine on this list, a project must be a fork of an existing FNF engine, such as Psych Engine, Kade Engine, or another legitimate FNF engine.

2. **Showcases Are Not Engines** — Projects created entirely from scratch are classified as showcases rather than FNF engines under this list's rules, even if they can run FNF songs or achieve excellent performance.

3. **Performance Doesn't Determine Classification** — A showcase can outperform every engine on this list, but it will still be classified as a showcase if it was built from scratch.

4. **Genuine Forks Only** — Simply renaming a project or claiming it is based on an existing engine is not enough. The project should have a verifiable connection to its original codebase.

5. **AI-Assisted Coding Is Allowed** — Using AI to help develop an engine is allowed. However, the project must still meet the engine classification requirements.

6. **Rankings Are Based on Personal Testing** — Rankings reflect my own opinions and performance tests using my lag tester. Results may vary depending on hardware, operating systems, and testing conditions.

7. **Community Suggestions Are Welcome** — Anyone can suggest an engine, correct information, or submit performance results through the Issues tab. Submissions may be tested before being ranked.

8. **Classification Comes First** — Before a project is ranked, it must qualify as an engine under these rules. Projects that do not qualify may be considered showcases instead.
